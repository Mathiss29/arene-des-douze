# Arène des Douze

Fan game gratuit à la Summoners War: Sky Arena dans l'univers de Dofus 3. Dofus © Ankama, jeu non officiel.

```bash
npm install
npm run dev      # http://localhost:5173
npm test         # tests de la sim et des données
npm run build    # vérification des types + build
```
